# ChooseOneAnswer.com starter

A lightweight static MVP for ChooseOneAnswer.com.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Deploy with GitHub and Vercel
1. Create a new GitHub repository named `chooseoneanswer`.
2. Upload these three files.
3. In Vercel, click **Add New Project**.
4. Import the GitHub repository.
5. Keep the default static-site settings and deploy.
6. Add `chooseoneanswer.com` and `www.chooseoneanswer.com` in Vercel Domains.
7. Update the DNS records in Cloudflare as instructed by Vercel.
